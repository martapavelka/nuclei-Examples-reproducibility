# Exhaustive search for nuclei on 11 vertices

All 1,249 combinatorial triangulations of S^2 on 11 vertices were generated by plantri.
For each boundary sphere, the same necessary incidence/reducedness/interior-tetrahedron/link-Euler model used in the vertex lower-bound computation was imposed. Fillings were then exhaustively enumerated at each tetrahedron count and passed through `exact_check`.

The general edge-count bounds give 14 <= t <= 36. The exhaustive search found no feasible arithmetic filling at all for t <= 29.

Total feasible fillings for t=30,...,36: 1,829.

Every rejected feasible filling at t=30,...,36 failed the homology test with mod-2 Betti numbers (1,1,1,0). The sole survivor is exactly N_00, with f-vector (11,54,79,35). N_00 has independently been verified to be a 3-ball (including an explicit simplicial collapse to a point).

Consequently, subject to the same computational trust assumptions as the lower-bound package:

1. Every 11-vertex nucleus has at least 35 tetrahedra.
2. N_00 attains this bound.
3. N_00 is the unique 11-vertex nucleus up to combinatorial isomorphism.
4. In particular, there is no 11-vertex nucleus with 36 tetrahedra.

Important logical point: `exact_check` is only used to reject non-balls here. All alternatives to N_00 are rejected already by nontrivial mod-2 homology. The assertion that N_00 itself is a ball rests on its separate positive verification/collapse certificate.
